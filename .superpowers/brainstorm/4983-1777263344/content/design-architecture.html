Stack técnico
Supabase Auth
Magic link por email. Sin contraseñas. El usuario recibe un link y entra directo.
Supabase Database
PostgreSQL. Posts, likes, comentarios, bookmarks, reposts, perfiles.
Supabase Storage
Bucket para audios del Melody Bank e imágenes adjuntas en posts.
Next.js (ya existente)
Supabase client directo en componentes. Sin API routes extra para el feed básico.
